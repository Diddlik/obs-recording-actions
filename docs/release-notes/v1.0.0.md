Native Recording Actions plugin for OBS Studio on Windows x64.

- Two configurable stop-and-move destinations with Unicode display aliases.
- One permanent stop-and-delete action.
- OBS hotkeys, persisted bindings, modeless Tools settings, and an About dialog.
- Collision protection, safe cross-volume copies, background retries, and cancellation.
- Optional logging, disabled by default.

Download `obs-recording-actions-1.0.0-windows-x64.zip`, close OBS, and extract it into `%ProgramData%\obs-studio\plugins`. Buildable corresponding source is included in `obs-recording-actions-1.0.0-source.zip`; SHA-256 hashes are in `SHA256SUMS.txt`.

Disable OBS automatic remuxing before using the action hotkeys. Delete permanently removes the completed file. For split recordings, only the final file reported by OBS is processed.

Built against OBS Studio 32.2.2 with C++17 and Qt 6. Debug and Release tests cover real file operations and a simulated OBS frontend. Full interactive recording, encoder, theme, and DPI acceptance checks remain manual. Updates use manual ZIP installation.
