# Recording Actions 1.1.0

- Fix raw `Plugin.Name` and `Settings.*` labels with embedded locale fallback.
- Include English and German translations and a complete About dialog with version, license, third-party credits, and project link.
- Add optional automatic HTTPS update checks and manual checks from About. Updates can be postponed. Installer downloads are SHA-256 verified before saving.
- Add a Windows x64 installer and uninstaller. Close OBS before installing; setup installs both DLL and resources, preserves OBS settings, and never terminates OBS or recordings.

Use the `*-windows-x64-setup.exe` asset for installation, or the ZIP for manual installation. The source ZIP contains the corresponding source. `SHA256SUMS.txt` covers all packages. OBS 32.2.2 on Windows x64 is the supported runtime.

## Setup preview

Choose names and destination folders under **Tools → Recording Actions**. The screenshot uses GG and Highlights as examples. Logging is optional, and automatic update checks can be disabled here.

![Recording Actions destination settings](https://raw.githubusercontent.com/Diddlik/obs-recording-actions/main/docs/images/FolderSettings.png)

Assign your own shortcuts under **OBS Settings → Hotkeys**. Move descriptions follow the saved aliases; Delete permanently removes the completed recording.

![OBS recording action hotkeys](https://raw.githubusercontent.com/Diddlik/obs-recording-actions/main/docs/images/Shortcuts.png)

## Install and update

1. Download `obs-recording-actions-1.1.0-windows-x64-setup.exe` below and close OBS.
2. Run setup and select the OBS folder containing `bin/64bit/obs64.exe`.
3. Start OBS, configure the two targets, and assign your hotkeys.

Disable OBS automatic remuxing before using the actions. Automatic update checking is optional; **About → Check for updates** also checks manually. Installer downloads are checked against the release SHA-256 manifest. Close OBS and run the downloaded installer yourself; settings and hotkeys are preserved.

[Complete installation, usage, update, and troubleshooting guide](https://github.com/Diddlik/obs-recording-actions#install)
